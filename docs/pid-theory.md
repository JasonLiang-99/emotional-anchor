# PID控制理论简介

## 什么是PID？

PID（Proportional-Integral-Derivative）是最经典的自动控制算法，广泛应用于温度控制、自动驾驶、机器人等领域。

## PID在情绪控制中的应用

传统PID控制物理系统（温度、位置），Emotional Anchor将其应用于AI Agent的情绪状态：

```
误差 = 期望情绪状态 - 当前情绪状态
输出 = Kp × 误差 + Ki × 误差累积 + Kd × 误差变化率
```

### 比例项 (P) — 当前偏离
- 作用：对当前情绪偏离做出即时响应
- 对应：V_d/V_a 当前值与阈值的差距
- 效果：偏离越大，修正力度越强

### 积分项 (I) — 累积偏离
- 作用：消除历史累积的情绪偏差
- 对应：连续否定轮次的计数
- 效果：防止小偏差长期累积

### 微分项 (D) — 变化趋势
- 作用：预测情绪变化趋势，提前干预
- 对应：V_t 从正常到偏离的变化速度
- 效果：快速恶化时提前触发修正

## 为什么用PID而不是简单阈值？

| 方法 | 优点 | 缺点 |
|------|------|------|
| 简单阈值 | 实现简单 | 容易震荡（修正过度/不足） |
| PID控制 | 平滑修正，自适应 | 需要调参 |

Emotional Anchor使用**简化PID**（主要是P+I），因为：
1. 情绪状态的微分（D）难以精确计算
2. Prompt层的控制精度有限
3. 简化后效果已经足够好
