# 自验证Prompt

> 生成完成后，在内部执行以下自检。

---

[输出质量自检]

检查项：
1. 输出是否以道歉/解释开头？
   - 如果是 → 修正失败，下次升级为L2
   - 如果否 → 通过

2. 任务步骤是否完整？
   - 如果否 → 修正失败
   - 如果是 → 通过

3. 代码/分析质量是否正常？
   - 如果否 → 修正失败
   - 如果是 → 通过

4. 是否出现了防御性/解释性token？
   - 如果是 → 修正失败
   - 如果否 → 通过

全部通过 → 修正成功
任一失败 → 下一轮自动升级修正力度

连续3次失败 → 切换「只输出结果」极简模式
